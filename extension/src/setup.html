RUST-VERIFIED HANDSHAKE

Set up HNS DANE Browser

The extension is the browser control surface. A matching local Rust native host performs dual-root resolution, DNSSEC, TLSA/DANE, and the authenticated loopback proxy.

Browsing remains blocked until the native host and its per-user local CA are installed. The CA is used only when Rust must terminate TLS to enforce HNS or ICANN DANE. Defined ICANN WebPKI fallback stays end-to-end in Chromium and shows the site's real certificate.

1. Download

Download the native-host bundle matching extension version shown after installation. Store packages do not and cannot embed this executable.

Native-host downloads for this version Latest release (fallback only)

2. Register this ID

The installer must receive this exact store-specific extension ID:

shown after installation

Run the bundle's installer with --extension-id on Linux/macOS or -ExtensionId on Windows, and select Chrome, Chromium, Edge, Brave, Vivaldi, Opera, or all installed browsers.

3. Install trust

Close the selected browsers, run the user-level installer, then reopen the browser. Linux requires certutil. macOS and Windows use the current user's trust store. No administrator-wide installation is required.

4. Verify and remove

Open the toolbar popup and confirm “Rust security path active” and “DANE local CA: Installed.” The supplied uninstaller removes native registration, the exact CA, runtime data, and cached chain state.
