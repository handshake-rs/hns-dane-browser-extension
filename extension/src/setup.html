RUST-VERIFIED HANDSHAKE

Set up HNS DANE Browser

The extension is the browser control surface. A matching local Rust native host performs dual-root resolution, DNSSEC, TLSA/DANE, and the authenticated loopback proxy.

Browsing remains blocked until the native host and its per-user local CA are installed. The CA is used only when Rust must terminate TLS to enforce HNS or ICANN DANE. Defined ICANN WebPKI fallback stays end-to-end in Chromium and shows the site's real certificate.

1. Download Setup

Download HNS DANE Browser Setup version shown after installation for your operating system and CPU. Each package contains the matching Rust native host and non-system runtime dependencies. Linux Setup requires glibc 2.39 or newer (Ubuntu 24.04 / Debian 13 generation).

Setup downloads for this version Latest release (fallback only) Manual native-host packages

2. Copy this exact ID

Setup must receive this exact store-specific extension ID:

shown after installation

Catalogs can assign different IDs. Do not copy an ID from documentation or another browser installation.

3. Run Setup

Close the selected browsers, open the downloaded setup application, paste the exact ID, select every Chromium flavor you use, and choose Install or Repair. Setup registers the native host and installs its local CA for the current user.

4. Verify or remove

Open the toolbar popup and confirm “Rust security path active” and “DANE local CA: Installed.” Setup also provides Complete Uninstall, which removes registrations, the exact CA, runtime data, and cached chain state.
