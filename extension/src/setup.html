Set up Shakescape

The extension is the browser control surface. Its matching local Rust native component performs dual-root resolution, DNSSEC, TLSA/DANE, and the authenticated loopback proxy.

Browsing remains blocked until the matching native component and its per-user local CA are installed. The CA is used only when Rust must terminate TLS to enforce HNS or ICANN DANE. Defined ICANN WebPKI fallback stays end-to-end in Chromium and shows the site's real certificate.

1. Download the embedded Setup

This extension contains Shakescape Setup version shown after installation. The matching package for your system is selected locally; no website download or operating-system information upload is needed.

Setup includes the matching Rust native component, non-system runtime dependencies, and the validated Handshake header snapshot through block 300,000.

2. Run Setup

Extract the downloaded package, close every supported Chromium browser, and open the Setup application. The catalog extension IDs are built into the signed Setup; choose every browser you use, then select Install or Repair.

Re-run this newly embedded Setup whenever the extension reports that its native component is out of date. Setup preserves current-user settings while replacing the native application and repairing its registrations and local CA.

3. Verify

Reopen the browser, select Retry in the toolbar popup, and confirm “Rust security path active” and “DANE local CA: Installed.”

Complete Uninstall

Complete Uninstall removes the native registrations, the exact per-user local CA, native runtime data, settings, and cached Handshake chain state. Removing the extension alone does not perform that operating-system cleanup.

This is the destructive option. Export anything you intend to retain, then close every supported Chromium browser before continuing.

  1. Download and extract the same Setup package selected above.
  2. Open Setup and choose Complete Uninstall.
  3. Review and accept Setup's explicit removal confirmation.
  4. After Setup succeeds, remove this extension from the browser.
