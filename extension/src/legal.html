Optional P2P relay use is off by default, and recursive HNS DoH is not contacted unless you enter and apply its URL in Settings.

User agreement

This is experimental Handshake-first browser software. Its extension and matching local native component perform dual-root resolution, local Handshake proof and DNSSEC validation, TLSA/DANE enforcement, and authenticated loopback proxying. Resolution, validation, proxy operation, optional relay or recovery transports, setup, and header synchronization may fail closed or be incomplete.

Handshake WebPKI fallback is prohibited. Optional relay and recovery answers never bypass local DNSSEC, TLSA, or DANE validation. Where the native policy selects defined ICANN WebPKI fallback, Chromium owns the end-to-end public-certificate connection. The requester-only P2P relay does not make this device an output node.

This release's Setup does not contain or install a wallet service. Current provider and value operations remain unavailable unless a separately released wallet service passes its native authenticity, version, and browser-authority gates. Any future qualified wallet service would remain separate and opt-in, and each value-bearing website request would remain approval-gated. HNS DANE Browser does not guarantee assets, name ownership, transaction settlement, website availability, or network availability, and is not a financial service. The software is provided without warranties except where applicable law requires otherwise. The bundled license contains the controlling license terms.
