Extension settings

Handshake authority, cryptography, transports, and proxy credentials stay in the native Rust host. Changes create a fresh proxy generation.

Recursive HNS DoH recovery Optional last resort after direct authoritative DNS, owner-authenticated DoH, and any opted-in P2P requester path are unavailable. Returned DNSSEC and DANE evidence is still verified locally.

Privacy: when selected, the operator sees HNS qnames and qtypes, request timing, and your source IP. The browser sends nothing to a recursive HNS DoH operator while this field is blank. The HNSDoH pool URL above is an example only and is never prefilled or contacted automatically; Zorro is a listed pool node, not a separate documented URL. Read the bundled privacy policy.

If your network intercepts port 53, enable this requester or configure the recursive HNS DoH recovery URL above. Site owners can avoid user configuration by publishing proof-anchored authoritative DoH on HTTPS 443: use an HNS hnsdns=1 declaration with proven glue plus a TLSA pin, or a supported authenticated _dns.<NS> SVCB record.
